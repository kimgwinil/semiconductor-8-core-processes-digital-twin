# SEMICONDUCTOR 8 CORE PROCESSES DIGITAL TWIN

Interactive training digital twin for the eight core semiconductor processes.

## Access policy

- The GitHub Pages application is a read-only deployment. Visitors can operate the training controls in their browser but cannot change the deployed source.
- Only repository owners and explicitly authorized collaborators can push changes to the original repository.
- Browser training state remains local to each visitor and does not write to the repository.

## Local development

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 3000
```

## Verification

```bash
npm run verify
```
