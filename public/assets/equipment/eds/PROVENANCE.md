## 0-A. 생성 엔진·모델명

**Claude Code / SVG 직접 제작 — 생성형 이미지 모델 미사용.**

- 확산모델·이미지 생성 API(Gemini `gemini-3-pro-image` 포함)를 **한 번도 호출하지 않았다.**
- 모든 도형은 SVG 프리미티브(`rect` `path` `circle` `line` `pattern` `linearGradient`)를 **좌표로 계산해 직접 기술**했다. 특히 프로브 침 다발은 **수직형(버티컬) 카드의 침 굴곡**을 좌표식으로 생성했다.
- 색은 전부 `var(--xs-*, 폴백)` 토큰. **hex 직접 기입 0 · 금지 상태색 0**(§5 자체 검증 참조).
- 래스터화: Chrome `--headless=new --window-size=1600,900 --force-device-scale-factor=1` → `cwebp` 품질 자동 하강. **실측 47,194 B · q=92**(한도 184,320 B 의 26 %).
- **재현:** `python3 이미지/_render.py eds` — 마스터 SVG 로부터 바이트 단위로 다시 만들어진다.

🔴 **왜 생성형을 쓰지 않았나.** 이 컷은 **오버드라이브·스크럽 마크 확대 인셋**이 핵심이고, 그 형상은 특허 부호 단위로 근거가 붙어야 한다(A13). 생성 모델 출력물은 어느 화소가 어느 근거에서 왔는지 추적할 수 없어 **A8·A13 을 원리적으로 충족하지 못한다.**
