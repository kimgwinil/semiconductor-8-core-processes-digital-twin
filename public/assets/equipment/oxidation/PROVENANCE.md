## 1. 생성 엔진·모델명

**Claude Code / SVG 직접 제작 (생성형 미사용)**

- 이미지 생성 모델(Diffusion·GPT-Image·Midjourney 등)을 **일절 사용하지 않았다.**
- SVG 요소(`rect` `path` `circle` `pattern` `linearGradient`)를 좌표 단위로 직접 기술해 작성했다.
- 작성 보조: Python 3 스크립트로 반복 요소(웨이퍼 21단, 히터 5존, 열전대 접점 5점, 분사구 6점)의 좌표를 산출해 SVG 텍스트를 생성. 스크립트는 좌표 계산만 하며 형상을 학습·모사하지 않는다.
