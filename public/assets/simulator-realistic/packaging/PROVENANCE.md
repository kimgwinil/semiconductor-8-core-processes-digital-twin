### 4. 참조한 공개 자료 — A13 근거

| 근거 | 뒷받침하는 형상 | 반영 위치 |
|---|---|---|
| **MIL-STD-883G/H METHOD 2019.7·2019.8** *Die Shear Strength* (US DoD, 2003·2010) | 힘은 "**parallel with the plane of the header or substrate**" · 접촉툴은 "**shall not move vertically** such that contact is made with the header/substrate" · 장비 요건에 **10배 이상 현미경** | 수평 가력 화살표 · 툴이 기판에 닿지 않는 간극 · 상부 대물렌즈 |
| **MIL-STD-883G METHOD 2011.7** *Bond Strength (Destructive Bond Pull Test)* (US DoD, 1989) | 풀 시험은 "**inserting a hook under the lead wire**" 후 기판면에 "**approximately normal**" 하게 당긴다 | 🔴 **배제 근거** — 훅 0개 · 수직 인장 화살표 0개 |
| 특허 **US6341530B1** (전단시험 장치) | 툴 높이는 "**typically within ±0.001 mm**" 로 관리 · 실험 전단 높이 **1 / 2 / 5 µm** · 하중은 **스트레인 게이지** | 좁은 전단 높이 간극 · 툴 뒤 카트리지 안 로드셀 |
| 특허 **US6213378B1** (극미세 피치 와이어본딩) | 70 µm 피치에서 패드 60×60 µm, **볼 지름 46~51 µm** · 25 µm 와이어 → 35~37 µm 풋프린트 | 볼:패드 비 · 눌린 볼의 납작한 형상 |
| **xyztec** 기술자료 *How to: shear test* / *Total ball shear* | **레이크 0° · 클리어런스 약 +5°** · 팁 반경 5~10 µm · 시료를 "**clamping firmly down to a rigid surface**" · 착지 → step back → 수평 전진 | 툴 전면 수직 평면 · 아랫면만 후퇴 · 상부 클램프 · 포켓 고정 |
| **Oricus Semicon** 볼 전단 툴 카탈로그 | 팁 폭 **0.51 / 0.76 mm** · 두께 **0.13 / 0.25 mm** | 툴이 볼보다 압도적으로 크다 |
| **Knowles Capacitors** 응용노트 | 풀 시험은 12~15 gf 초과 시 **본드가 아니라 와이어 강도**를 재게 된다 → 그래서 전단이 필요하다 · 루프 높이 50~400 µm | 와이어를 **느슨하게**(하중 경로가 아님) · 루프 높이 |
| **ASTM F1269-13(2018)** *Destructive Shear Testing of Ball Bonds* (2023-11-30 폐지) | "shear test **ram**" · "**clearance above the bonding pad**" | 램 형상 · 패드 위 간극 |
| **JEDEC JESD22-B116B** *Wire Bond Shear Test* (2017-04-01) | 와이어본딩 볼본드 전단의 소관 표준 | 시험 종류 식별 |
| **xyztec Sigma** 제품 페이지 | 벤치탑 620×558×608 mm · XY 스테이지 370/168 mm · step back ±1 µm | XY 스테이지 · 컬럼·빔 구성 |

### 5. 검수조 전달 사항

**5-1. 고지** — 개념 도해다. **실제 사진이 아니다.** 특정 제조사 장비의 복제가 아니다. **현업 검증 전**(D-009).

**5-2. 🔴 미확인 · 지시서 전제 정정**
- 🔴 **`JESD22-B117` 은 이 자산의 근거가 아니다.** 정확한 제목은 ***Solder Ball Shear*** 로 **솔더볼(BGA·플립칩)** 대상이다.
  와이어본딩 볼본드 전단은 **JESD22-B116**(*Wire Bond Shear Test*) 과 **ASTM F1269** 소관이다.
  (본 재제작 지시서가 B117 을 "ball shear" 로 적었으나 원문 확인 결과 그렇지 않았다.)
- 🔴 **JESD22-B116 / B117 의 본문은 유료라 열지 못했다.** 확인한 것은 **번호·제목·발행처·연도**까지다.
  **그 표준이 규정하는 전단 높이 수치는 확인하지 않았다** — 그래서 도해에 수치를 표기하지 않았다.
- 🔴 **눌린 볼의 높이(µm) 명시 원문을 못 찾았다.** 따라서 「전단 높이 = 볼 높이의 N %」 환산은 하지 않았다.
- ⚠️ 도해는 **볼 전단(ball shear)** 을 그렸다. 같은 실습이 다루는 **다이 전단**은 툴이 다이 한쪽 모서리에 **end-to-end 선접촉**하는 다른 그림이다(M2019). 다이 전단 도해가 따로 필요한지는 **PLN 판정 사항**이다.

**5-3. 과장한 치수와 실제 비**

| 요소 | 도해 비 | 실제 비 | 사유 |
|---|---|---|---|
| 전단 높이 간극 / 볼 지름 | 26/130 = **20 %** | 1~5 µm / 27~51 µm ≈ **2~18 %**, 통상 ≤10 % | 🔴 **약 2배 과장.** 간극이 0이면 「툴이 기판에 닿는다」는 정반대 오개념이 된다 |
| 툴 두께(전후) / 볼 지름 | 244/130 = **1.9** | 0.13~0.25 mm / 27~51 µm = **2.5~9** | ⚠️ **실제보다 작게 그렸다.** 더 키우면 화면을 다 덮는다 |
| 볼 높이 / 볼 지름 | 65/130 = **0.50** | `[미확인]` — §5-2 | 눌린 볼의 통상 형상 |
| 루프 높이 / 볼 지름 | ≈0.65 | 50~400 µm / 27~51 µm = 1~15 | ⚠️ 축소. 루프를 키우면 전단부가 작아진다 |

**5-4. 문자·구도 규칙** — 래스터에 문자를 굽지 않았다(ko/en 공유).

**5-5. 🟢 풀 시험과 구분되는 지점 3가지 (검수 시 이것을 본다)**
1. **힘의 방향** — 기판면에 **평행·수평**. 수직 상방 화살표가 없다.
2. **공구** — **평평한 치즐 날**이 패드 표면 바로 위. **갈고리가 없다.**
3. **와이어** — **느슨하다.** 팽팽하게 들려 있지 않고 하중 경로가 아니다.
